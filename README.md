### Hi there 👋!

I'm **Juanpe Catalán**, a **Senior iOS Engineer** from **Sevilla**, in the South of Spain. I've been building apps for Apple platforms **since 2010**, and these days I focus on **AI in Swift apps, on device and in the cloud**.

- 🧩 [**ModelRelay**](https://github.com/Juanpe/ModelRelay): a Swift package to compose on-device and cloud model steps into one workflow.
- 📱 [**Runline**](https://runline.juanpecatalan.com/): build model workflows visually and run them from Shortcuts. On the [App Store](https://apps.apple.com/app/id6824289539).
- ⚙️ [**Automation Studio**](https://automationstudio.juanpecatalan.com/): a native n8n client for Mac, iPad and iPhone.
- ☠️ [**SkeletonView**](https://github.com/Juanpe/SkeletonView): an elegant way to show users that something is happening.
- 📚 [**About SwiftUI**](https://github.com/Juanpe/About-SwiftUI): everything published about SwiftUI, by Apple and by others.
